# 요구사항 명세 템플릿

AI에게 코드를 받기 전에 이 칸을 채우고, 아래 "프롬프트 틀"에 붙여 넣는다.

## 1. 만들 것 (한 문장)
(예: 서울 리전에 2개 AZ로 나뉜 VPC를 만든다)

## 2. 구성 요소와 값
| 항목 | 값 |
|---|---|
| 리전 | ap-northeast-2 |
| (예) VPC CIDR | 10.40.0.0/16 |
| (예) 서브넷 | 퍼블릭 2개, 프라이빗 2개, AZ마다 하나씩 |

## 3. 제약 조건
- Terraform 1.17, AWS Provider 6.x 문법만 쓴다 (폐기된 인자 금지)
- provider·terraform 블록은 쓰지 않는다 (versions.tf에 이미 있다)
- AMI ID·AZ 이름·계정 ID를 하드코딩하지 않는다 (데이터 소스 사용)
- 비밀번호·키를 코드에 넣지 않는다
- 보안 그룹은 필요한 포트만 연다

## 4. 출력 형식
- main.tf 하나로, 리소스마다 한 줄 한국어 주석
- 마지막에 output 블록

---

## 프롬프트 틀 (복사해서 쓴다)

```
너는 AWS와 Terraform 전문가다.
아래 요구사항을 만족하는 Terraform 코드를 작성해 줘.

[요구사항]
(위 1~2절 붙여 넣기)

[제약]
(위 3절 붙여 넣기)

[출력]
(위 4절 붙여 넣기)
```
